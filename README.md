# The project
*Started Apr 2022 — personal project*

Built a programmable 16-bit computer from logic gates up, inspired by ["The Elements of Computing Systems"](https://www.nand2tetris.org/) (nand2tetris).

Implemented in [Logisim Evolution](https://github.com/logisim-evolution/logisim-evolution): ALU, CPU, program counter, RAM, custom instruction set. To test it, I programmed it to compute the Fibonacci sequence.
